# E-Commerce Return Analysis & Prediction

## 📌 Project Overview

This project analyzes e-commerce transaction data to understand the factors associated with product returns and predict the likelihood of a customer returning an order.

The project combines **Python, Machine Learning, SQL, and Power BI** to perform data cleaning, exploratory analysis, predictive modeling, and business intelligence.

## 🎯 Objectives

* Analyze e-commerce transaction and return patterns.
* Identify categories and regions with higher return rates.
* Perform data cleaning and feature engineering.
* Build machine learning models to predict product returns.
* Generate return probability and customer/order risk scores.
* Analyze the results using SQL.
* Create an interactive Power BI dashboard.
* Generate business insights that can help reduce product returns.
