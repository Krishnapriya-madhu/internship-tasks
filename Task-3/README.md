The dataset contains information such as order details, customer information, product categories, regions, payment methods, delivery time, customer ratings, and revenue.
A database named ecommerce_analysis was created, and the e-commerce sales CSV file was imported into a MySQL table named ecommerce_sales. 
SQL queries were used to perform data exploration and analysis.
The analysis included basic SQL operations such as SELECT, WHERE, and ORDER BY to retrieve, filter, and sort data. 
Aggregate functions like SUM(), AVG(), and COUNT() were applied to calculate total revenue, average customer ratings, and overall sales metrics. 
GROUP BY queries were used to analyze revenue based on product categories and regions.
To understand relationships between datasets, an additional customer details table was created, and different types of joins including INNER JOIN, LEFT JOIN, and RIGHT JOIN were implemented to combine customer and sales information.
Subqueries were used to identify high-value orders and compare sales performance against average revenue. 
A view was created to store frequently used analysis queries, making future analysis easier. 
An index was created on customer ID to improve query performance and optimize database operations.
